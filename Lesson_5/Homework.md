## Задание 1. Функция вывода в заданный поток

### 1.1. Задание
Напишите функцию, которая выводит текст в заданный в аргументе пользователем поток (стандартный поток вывода, стандартный поток ошибок, файл).

### 1.2. Команды
Использую редактор `nano` для создания скрипта `quest.sh`:

```bash
print_to() {
    local text="$1"
    local dest="$2"

    if [ "$dest" = "stdout" ]; then
        echo "$text"
    elif [ "$dest" = "stderr" ]; then
        echo "$text" >&2
    else
        echo "$text" > "$dest"
    fi
}

print_to "Hello quest" "stdout"
print_to "Hello quest" "file.txt"
```

Запуск скрипта и проверка выполнения:
```bash
chmod +x quest.sh
./quest.sh
```

## Задание 2. Функция информации о системе

### 2.1. Задание
Напишите функцию, которая будет выводить текущую информацию о системе. Функция должна принимать аргумент в виде описания запрошенного параметра (например, рабочая директория — pwd, текущий пользователь — user, версия — version и т.д.).

### 2.2. Команды
Использую редактор `nano` для создания скрипта `quest2.sh`:

```bash
sysinfo() {
    local param="$1"

    if [ "$param" = "pwd" ]; then
        pwd
    elif [ "$param" = "user" ]; then
        whoami
    elif [ "$param" = "version" ]; then
        uname -a
    elif [ "$param" = "date" ]; then
        date
    else
        echo "Unknown: $param"
    fi
}

sysinfo "pwd"
sysinfo "user"
sysinfo "version"
```

Запуск скрипта и проверка выполнения:
```bash
bash quest2.sh
```

## Задание 3. Функция вывода переменной через eval

### 3.1. Задание
Напишите функцию, которая выводит значение переменной по ее названию. Для реализации используйте команду eval. Напишите с ней программу для вывода значения переменных по имени. Она должна выполняться до отправки в терминал комбинации клавиш Ctrl + D (состояние EOF стандартного потока ввода).

### 3.2. Команды
Использую редактор `nano` для создания скрипта `quest3.sh`:

```bash
print_var() {
    local var_name="$1"
    eval echo \$$var_name
}

echo "Enter variable name (Ctrl+D to exit):"
while read -r input; do
    print_var "$input"
done
```

Запуск скрипта и проверка выполнения:
```bash
bash quest3.sh
```

## Вопрос
Команда `EXIT` полностью закрывает скрипт и передаёт код завершения в ОС. Команда `RETURN` прерывает только работу функции, возвращая управление в основной код скрипта, который продолжает выполняться дальше.
