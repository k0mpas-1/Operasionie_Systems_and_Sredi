### 📝 Описание работы
В рамках данного домашнего задания были углублены навыки работы в интерфейсе командной строки (CLI) Linux. Практика охватывает управление файловой структурой (создание, перемещение, переименование), перенаправление потоков ввода-вывода (`>`), конвейеризацию команд, а также расширенную работу с текстовыми данными.

### 🛠️ Выполненные задачи и команды

| № | Описание задачи | Использованная команда |
|---|---|---|
| **1.1** | Создание каталога `work` | `mkdir work` |
| **1.2** | Переход в каталог `work` и вывод текущего пути | `cd work && pwd` |
| **1.3** | Создание пустого файла `file.txt` | `touch file.txt` |
| **1.4** | Заполнение файла текстом (первые 2 абзаца Гарри Поттера) | `cat file.txt` |
| **1.5** | Переименование файла `file.txt` в `book.txt` | `mv file.txt book.txt` |
| **1.6** | Выделение строк со словом `was` в отдельный файл `was.txt` | `grep was book.txt > was.txt` |
| **1.7** | Объединение файлов и подсчёт общего количества вхождений буквы `n` | `cat was.txt book.txt > combined.txt && grep -o n combined.txt \| wc -l` |
