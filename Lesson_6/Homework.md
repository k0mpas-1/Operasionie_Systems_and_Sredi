## Задание 1. Подготовка

### 1.1. Установка binutils
Убедитесь, что установлены компилятор ассемблера (as), компоновщик (ld) и make.

```bash
apt install -y binutils
```

### 1.2. Исходный файл main.s
Создайте файл с простым исходным кодом на ассемблере с расширением .s.

```assembly
.global _start
.text
_start:
    mov $1, %rax
    mov $1, %rdi
    mov $msg, %rsi
    mov $14, %rdx
    syscall
    mov $60, %rax
    xor %rdi, %rdi
    syscall
msg:
    .ascii "Hello, World!\n"
```

## Задание 2. Makefile

### 2.1. Создание Makefile
Создайте в каталоге проекта файл Makefile с целями main.o, main, clean, build и директивой .PHONY.

```makefile
main.o: main.s
	as -o main.o main.s

main: main.o
	ld -o main main.o

clean:
	rm -f *.o

build: main clean

.PHONY: clean build
```

Директива `.PHONY` указывает, что `clean` и `build` — абстрактные цели, не связанные с файлами.

### 2.2. Сборка одной командой
Выполните make build — сначала соберётся main, затем clean удалит .o файлы.

```bash
make build
```

### 2.3. Повторная сборка и clean
Повторный make build снова выполняет цепочку. make clean удаляет объектные файлы.

```bash
make clean
```
