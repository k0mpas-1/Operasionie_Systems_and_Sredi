### 📝 Описание работы
В рамках данного домашнего задания были изучены принципы функционирования и создания фоновых процессов (демонов/служб) в операционных системах Linux, а также механизмы управления ими с помощью подсистемы инициализации `systemd`. Практическая часть включает написание управляющего Bash-скрипта с обработкой системных сигналов (`SIGTERM`, `SIGINT`), логирование событий в системный журнал `syslog` через утилиту `logger`, создание собственного конфигурационного файла службы (`.service` юнит-файла) и управление жизненным циклом демона.

### 🛠️ Структура проекта и конфигурация

#### 1. Скрипт демона (`my_daedalus.sh`)
Размещен по пути `/home/user/my_daedalus.sh`. Скрипт циклически раз в 5 секунд отправляет маркер проверки в системный журнал и перехватывает сигналы завершения для корректной записи статуса остановки.
*   **Логирование запуска:** `[Daedalus] zapyshen`
*   **Логирование завершения:** `[Daedalus] ysmiren`
*   **Назначение прав на исполнение:**
    ```bash
    chmod +x /home/user/my_daedalus.sh
    ```

#### 2. Юнит-файл службы (`my_daedalus.service`)
Конфигурационный файл создан по пути `/etc/systemd/system/my_daedalus.service` для управления процессом через `systemd`:
```ini
[Unit]
Description=My Daedalus Service Daemon
After=syslog.service

[Service]
ExecStart=/home/user/my_daedalus.sh
Restart=no
```

### 💻 Управление службой и диагностика

| Этап / Задача | Выполненные команды |
|---|---|
| **Регистрация и запуск** | `systemctl daemon-reload` <br> `systemctl start my_daedalus` |
| **Мониторинг статуса** | `systemctl status my_daedalus` |
| **Проверка логов в реальном времени** | `systemctl start rsyslog` <br> `grep my_daedalus /var/log/syslog \| tail -5` |
| **Остановка службы** | `systemctl stop my_daedalus` |
| **Управление автозапуском** | `systemctl disable my_daedalus` |
