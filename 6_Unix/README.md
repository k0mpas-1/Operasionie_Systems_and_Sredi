### 📝 Описание работы
В рамках данного домашнего задания были освоены принципы автоматизации процесса сборки низкоуровневых программ в операционных системах Unix с использованием утилиты `make`. Практическая часть включает в себя развертывание инструментария `binutils`, написание простейшего исходного кода на языке ассемблера GNU Assembler (x86_64), а также составление конфигурационного файла `Makefile` для сборки бинарных файлов проекта, линковки и последующей очистки директории от промежуточных артефактов.

### 🛠️ Структура проекта и конфигурация

#### 1. Подготовка окружения и исходный код (`main.s`)
*   **Инструментарий:** Установлен пакет `binutils` (`as`, `ld`, `make`) с помощью пакетного менеджера:
    ```bash
    apt install -y binutils
    ```
*   **Программа:** Написана базовая программа "Hello, World!" на ассемблере, осуществляющая системные вызовы `sys_write` и `sys_exit` через `syscall`.

#### 2. Файл автоматизации сборки (`Makefile`)

Конфигурационный файл содержит описание зависимостей и правил для компиляции ассемблерного кода и компоновки объектных модулей:

```makefile
main.o: main.s
	as -o main.o main.s

main: main.o
	ld -o main main.o

clean:
	rm -f *.o

build: main clean

.PHONY: clean build
```

### 💻 Управление сборкой

| Команда | Выполняемое действие |
|---|---|
| `make` / `make main` | Компиляция `main.s` в объектный файл и его последующая компоновка (линковка) в исполняемый файл `main`. |
| `make build` | Полный цикл автоматизации: сборка исполняемого файла `main` с немедленным вызовом цели `clean`. |
| `make clean` | Удаление промежуточных объектных файлов (`.o`) для очистки рабочего пространства. |
