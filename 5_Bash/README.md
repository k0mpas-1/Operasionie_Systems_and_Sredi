    ```bash
    bash quest3.sh
    ```

### ❓ Теоретические вопросы
*   **В чем разница между `exit` и `return`?**
    Команда `exit` полностью прекращает выполнение всего скрипта и передаёт код завершения операционной системе. Команда `return` прерывает только выполнение текущей функции, возвращая управление в основное тело скрипта, который продолжает работать дальше.
