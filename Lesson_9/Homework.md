## Задание 1. Подготовка и создание окон

### 1.1. Установка tmux
Установите в системе консольный мультиплексор tmux.

```bash
apt install -y tmux
```

### 1.2. Запуск tmux
Запустите консольный мультиплексор. Чем отличается окно от обычного терминала?

```bash
tmux
```

**Ответ:** Окно tmux отличается от обычного терминала наличием строки статуса внизу и возможностью создавать несколько окон и панелей в одной сессии, которая сохраняется даже при отключении.

### 1.3. Создание нового окна
По обычной комбинации не открылось окно, через инет использовал команду:

```bash
tmux new-window
```

### 1.4. Переименование окна и запуск vim
Переименуйте текущее окно в Text (Ctrl+B, затем ,) и запустите в нём vim.

```bash
vim
```

## Задание 2. Использование разных окон

### 2.1. Скрипт на Python
В окне в vim напишите скрипт на Python для последовательной записи в файл `test.txt` количества секунд с его запуска.

Содержимое скрипта `time.py`:
```python
import time
f = open('test.txt', 'w')
t0 = time.time()
while True:
    f.write(str(int(time.time() - t0)) + '\n')
    f.flush()
    time.time.sleep(1)
```

### 2.2. Запуск скрипта
Запустите написанный скрипт в фоновом режиме:

```bash
python3 time.py &
```

### 2.3. Слежение за файлом через watch
Перейдите в предыдущее окно (Ctrl+B, 0). С помощью watch следите за изменением размера файла `test.txt`.

```bash
watch -n 1 ls -l test.txt
```

## Задание 3. Разделение окон

### 3.1. Завершение watch и скрипта, закрытие окна
Завершите работу watch (Ctrl+C) и отправьте сигнал прерывания в скрипт. Перейдите в первое окно (Ctrl+B, 1). Закройте второе окно командой `exit`.

### 3.2. Разделение по горизонтали и установка fastfetch
Разделите окно по горизонтали (Ctrl+B, %). В правой панели запустите установку пакета fastfetch.

```bash
apt install -y fastfetch
```

### 3.3. Запуск fastfetch
Перейдите в левую область и после окончания установки запустите fastfetch.

```bash
fastfetch
```

### 3.4. Закрытие областей
Закройте правую область командой `exit`. Ради эксперимента разделите окно по вертикали (Ctrl+B, "). По окончании закройте все области командами `exit`.

Все области закрыты. Сессия tmux завершена.
