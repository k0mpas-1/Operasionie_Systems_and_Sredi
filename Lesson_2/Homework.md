## Задание 1. Работа с каталогами и файлами

### 1.1. Создание каталога work
Создать каталог work.

```bash
mkdir work
```

### 1.2. Переход в каталог и pwd
Перейти в каталог work и вывести текущий путь.

```bash
cd work && pwd
```

### 1.3. Создание файла
Создать пустой файл file.txt.

```bash
touch file.txt
```

### 1.4. Заполнение файла текстом
Записать в файл первые два абзаца Гарри Поттера.

```bash
cat file.txt
```

### 1.5. Переименование файла
Переименовать file.txt в book.txt.

```bash
mv file.txt book.txt
```

### 1.6. Предложения со словом was
Выделить предложения, содержащие слово was, в файл was.txt.

```bash
grep was book.txt > was.txt
```

### 1.7. Подсчёт буквы n
Объединить файлы и посчитать количество вхождений буквы n.

```bash
cat was.txt book.txt > combined.txt && grep -o n combined.txt | wc -l
```
