### 📝 Описание работы
В рамках данного домашнего задания было изучено использование консольного мультиплексора `tmux` для эффективной организации рабочего пространства в терминале Linux. Практическая часть включает управление сессиями, создание и переименование окон, разделение экрана на панели (пайны), запуск фоновых скриптов на Python, а также мониторинг файлов в режиме реального времени с помощью утилиты `watch`.

### 🛠️ Выполненные задачи и управление

#### 1. Установка и базовая работа с окнами
*   **Установка мультиплексора:** `apt install -y tmux`
*   **Запуск сессии:** `tmux`
*   **Отличие от обычного терминала:** Наличие строки статуса, возможность разделения экрана на независимые области и сохранение работы сессии даже при случайном или преднамеренном отключении от сервера.
*   **Управление окнами:**
    *   Создание окна: `tmux new-window`
    *   Переименование в *Text*: `Ctrl + B`, затем `,`
    *   Запуск текстового редактора: `vim`

#### 2. Фоновые процессы и мониторинг
В окне *Text* был создан Python-скрипт `time.py` для ежесекундной фиксации тайминга в файл `test.txt`:
```python
import time
f = open('test.txt', 'w')
t0 = time.time()
while True:
    f.write(str(int(time.time() - t0)) + '\n')
    f.flush()
    time.sleep(1) # Исправлена опечатка в time.time.sleep
```
*   **Запуск скрипта в фоне:** `python3 time.py &`
*   **Переключение окон:** `Ctrl + B`, затем `0`
*   **Слежение за размером файла:** `watch -n 1 ls -l test.txt`

#### 3. Разделение панелей (Пайны)
*   Разделение по горизонтали (`Ctrl + B` + `%`): в правой панели выполнена установка пакета `fastfetch` (`apt install -y fastfetch`).
*   Разделение по вертикали (`Ctrl + B` + `"`): протестировано в рамках эксперимента с интерфейсом.
*   Вывод системной информации в левой панели: `fastfetch`.
