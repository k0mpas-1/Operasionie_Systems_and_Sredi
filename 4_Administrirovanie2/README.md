### 📝 Описание работы
В рамках данного домашнего задания были освоены базовые принципы конфигурирования сетевых интерфейсов в операционных системах на базе Linux и основы виртуализации сетей в VirtualBox. Практическая часть включает в себя работу с Host-Only адаптером, просмотр состояния сетевых стеков, ручное назначение статических IP-адресов, а также диагностику сетевой связности между хостом и гостевой системой.

### 🛠️ Выполненные задачи и команды

#### Раздел 1. Настройка Host-Only адаптера

| № | Описание задачи | Действие / Использованная команда |
|---|---|---|
| **1.1** | Подключение адаптера VirtualBox | В настройках ВМ добавлен *VirtualBox Host-Only Ethernet Adapter*. |
| **1.2** | Просмотр и анализ сетевых интерфейсов | `ip address` |
| **1.3** | Назначение статического IP-адреса | `ip address add 192.168.56.10/24 dev enp0s8` |

#### Раздел 2. Проверка связи (ping)

| № | Описание задачи | Использованная команда |
|---|---|---|
| **2.1** | Проверка сетевой связи с самим собой | `ping -c 4 192.168.56.10` |
| **2.2** | Проверка связи с основной хост-машиной | `ping -c 4 192.168.56.10` (выполняется на хосте) |
| **2.3** | Проверка связи с гостевой системой из хоста | `ping -c 4 192.168.56.10` (выполняется на хосте) |
