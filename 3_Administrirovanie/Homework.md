## Задание 1. Работа с процессами

### 1.1. Процессы в виде дерева
Отобразить процессы в виде дерева (иерархия родителей и потомков).

```bash
ps -ef --forest
```

### 1.2. Процессы не от root
Найти все процессы, запущенные не от имени root.

```bash
ps -u root -N
```

### 1.3. Пять процессов с наибольшим потреблением памяти
Вывести пять процессов, потребляющих больше всего памяти (с использованием head).

```bash
ps aux --sort=-%mem | head -6
```

### 1.4. Фоновые процессы
Вывести процессы, запущенные в фоновом режиме.

```bash
jobs -l
```

## Задание 2. Справочная система man

### 2.1. Аргумент cp для сохранения атрибутов
Открыть справку cp и найти аргумент, сохраняющий владельца, права и временные метки.

```bash
man cp
```

### 2.2. Поиск справки по ключевым словам
Найти аргумент man, позволяющий искать справки по ключевым словам.

```bash
man man
```

### 2.3. Команда apropos
Найти команду, делающую то же, что man -k, и найти страницы по слову copy.

```bash
apropos copy
```
