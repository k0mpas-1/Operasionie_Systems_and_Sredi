### 📝 Описание работы
В рамках данного домашнего задания были освоены базовые механизмы администрирования операционных систем семейства Linux. Практическая часть включает в себя мониторинг и управление процессами (исследование иерархии, фильтрация по пользователям, сортировка по ресурсоемкости), работу с фоновыми задачами, а также углубленное изучение встроенной справочной системы для быстрого поиска параметров команд.

### 🛠️ Выполненные задачи и команды

#### Раздел 1. Работа с процессами

| № | Описание задачи | Использованная команда |
|---|---|---|
| **1.1** | Отображение процессов в виде дерева (иерархия родителей и потомков) | `ps -ef --forest` |
| **1.2** | Поиск всех процессов, запущенных не от имени root | `ps -u root -N` |
| **1.3** | Вывод топ-5 процессов с наибольшим потреблением памяти | `ps aux --sort=-%mem \| head -6` |
| **1.4** | Вывод списка процессов, запущенных в фоновом режиме | `jobs -l` |

#### Раздел 2. Справочная система man

| № | Описание задачи | Использованная команда |
|---|---|---|
| **2.1** | Поиск аргумента `cp` для сохранения владельца, прав и временных меток | `man cp` *(аргумент `-p` или `--preserve`)* |
| **2.2** | Поиск аргумента `man` для полнотекстового поиска страниц по ключевым словам | `man man` *(аргумент `-k`)* |
| **2.3** | Использование альтернативной команды поиска страниц по слову `copy` | `apropos copy` |
