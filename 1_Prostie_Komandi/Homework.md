## Задание 1. Работа с командами ls, cat, grep, find

### 1.1. Файлы .log в /var/log
Вывести список файлов с расширением .log в каталоге /var/log.

```bash
ls /var/log/*.log
```

### 1.2. Файлы /usr/bin по размеру
Вывести файлы в /usr/bin, отсортированные по размеру.

```bash
ls –lS /usr/bin
```

### 1.3. Содержимое sources.list
Просмотреть содержимое файла /etc/apt/sources.list.

```bash
cat /etc/apt/sources.list
```

### 1.4. Строки с root в /etc/passwd
Найти строки, содержащие root, в файле /etc/passwd.

```bash
grep root /etc/passwd
```

### 1.5. Строки без комментариев в /etc/services
Вывести строки без комментариев из /etc/services.

```bash
grep -v '^#' /etc/services | grep -v '^\$'
```

### 1.6. Файлы *.conf в /etc
Найти файлы *.conf и *.conf.d в /etc.

```bash
find /etc  -name "*.conf" -o -name "*.conf.d" 
```

### 1.7. Символические ссылки в корне
Найти символические ссылки в корне файловой системы.

```bash
find / -maxdepth 1 -type l | wc -l
```

### 1.8. Каталоги в /usr/share
Найти каталоги в /usr/share глубиной не более 2.

```bash
find /usr/share -maxdepth 2 -type d
```

### 1.9. Файлы в /var от root
Найти файлы в /var, принадлежащие root.

```bash
find /var -user root -type f
```

### 1.10. Файлы в /etc с root
Найти файлы в /etc, содержащие слово root.

```bash
find /etc -maxdepth 2 -type f -exec grep -l root {} \;
```
