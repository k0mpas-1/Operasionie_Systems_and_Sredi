### 📝 Описание работы
В рамках данного домашнего задания были отработаны базовые навыки работы в CLI (интерфейсе командной строки) операционных систем на базе Linux. На практике применены утилиты для поиска, фильтрации, сортировки и просмотра содержимого файлов.

### 🛠️ Выполненные задачи и команды

| № | Описание задачи | Использованная команда |
|---|---|---|
| **1.1** | Список файлов `.log` в `/var/log` | `ls /var/log/*.log` |
| **1.2** | Файлы `/usr/bin`, отсортированные по размеру | `ls –lS /usr/bin` |
| **1.3** | Просмотр содержимого `sources.list` | `cat /etc/apt/sources.list` |
| **1.4** | Поиск строк с `root` в `/etc/passwd` | `grep root /etc/passwd` |
| **1.5** | Вывод строк без комментариев из `/etc/services` | `grep -v '^#' /etc/services \| grep -v '^\$'` |
| **1.6** | Поиск файлов `*.conf` и `*.conf.d` в `/etc` | `find /etc -name "*.conf" -o -name "*.conf.d"` |
| **1.7** | Подсчет символических ссылок в корне (`/`) | `find / -maxdepth 1 -type l \| wc -l` |
| **1.8** | Поиск каталогов в `/usr/share` (глубина \(\le\) 2) | `find /usr/share -maxdepth 2 -type d` |
| **1.9** | Поиск файлов в `/var`, принадлежащих пользователю `root` | `find /var -user root -type f` |
| **1.10**| Поиск файлов в `/etc`, содержащих текст "root" | `find /etc -maxdepth 2 -type f -exec grep -l root {} \;` |
