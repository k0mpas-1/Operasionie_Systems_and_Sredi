### 📝 Описание работы
В рамках данного домашнего задания были изучены практические аспекты резервного копирования, обеспечения отказоустойчивости и восстановления операционных систем с использованием механизма снимков (снапшотов) в среде виртуализации VirtualBox. Была проведена симуляция критического сбоя ОС путем преднамеренного разрушения корневой файловой системы под учетной записью суперпользователя с последующим успешным восстановлением работоспособности виртуальной машины из резервной точки.

### 🛠️ Ход выполнения и симуляция сбоя

| Этап / Шаг | Описание действий | Результат / Наблюдения |
|---|---|---|
| **1. Создание снимка** | Фиксация стабильного состояния ОС перед выполнением потенциально опасных операций. | Создана контрольная точка восстановления. |
| **2. Симуляция сбоя** | Выполнение деструктивной команды с привилегиями `root`: <br> `su` <br> `rm -rf / --no-preserve-root > /dev/null` | Полное удаление системных файлов. После принудительного перезапуска ВМ загрузка заблокирована ошибкой: <br> `error: file '/boot/grub/i386-pc/normal.mod' not found.` <br> `grub rescue>` |
| **3. Восстановление** | Запуск процесса отката состояния виртуальной машины к созданному снапшоту в меню VirtualBox. | Система полностью восстановлена до исходного состояния без потери данных. |
